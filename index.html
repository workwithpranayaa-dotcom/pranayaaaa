About Me

I'm studying Bachelors in Information Technology Management at Tribhuvan University in Kathmandu, Nepal. My main focus is full-stack development.

I like taking an idea through every layer: designing the screen in Figma, building it in React, and connecting it to a database through an API.

Recently I have been building projects that go beyond basic CRUD: real-time collaboration over WebSockets, a debt-settling algorithm, SQL-driven analytics dashboards, and a collaborative code editor built on CRDTs. I work comfortably with PostgreSQL, MySQL and MongoDB.
